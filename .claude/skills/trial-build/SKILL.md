# Пробная сборка на телефон

APK собирает CI (`.github/workflows/ci.yml`, задача «Сборка APK»), не локальная машина: в облачной сессии нет
Android SDK и ключа подписи. Телефон — Galaxy S10 (Exynos, Mali-G76).

## Перед запуском
1. Рабочая ветка закоммичена и отправлена: `git status` чист, `git push -u origin <ветка>`.
2. Предупредить пользователя: **коммиты этой ветки потом нельзя убирать из истории** (squash, rebase,
   force-push с удалением). Номер сборки = `git rev-list --count HEAD`; если в `main` он станет меньше
   установленной пробной сборки, Android не поставит обновление — только удаление вместе с данными.
   Сообщить номер: `git rev-list --count HEAD`.

## Запуск
1. Загрузить инструменты GitHub (`ToolSearch` → `mcp__github__actions_run_trigger`, `mcp__github__actions_list`,
   `mcp__github__actions_get`, `mcp__github__get_job_logs`).
2. Запустить workflow `ci.yml` на ветке (`ref` = имя ветки) — это workflow_dispatch.
   Push в ветку с открытым PR тоже запускает CI — тогда отдельный запуск не нужен.
3. Не опрашивать в цикле: сборка идёт ~15–25 минут (тесты + APK). Проверить один раз через разумное время
   или подписаться на PR (`subscribe_pr_activity`), если он есть.

## Результат
- Упало — прочитать журнал упавшей задачи (`get_job_logs`), исправить, повторить. Не отключать тесты ради зелёного.
- Успех — дать ссылку на запуск: `https://github.com/Yrgez/LifeOS/actions/runs/<id>`, артефакт
  `catenna-<версия>-<сборка>` (хранится 14 дней). Скачать на телефон, открыть, «Обновить».
- Посмотреть в сводке запуска отпечаток подписи (`certificate SHA-256 digest`). Предупреждение
  «Секрет LIFEOS_KEYSTORE_BASE64 не задан» означает отладочную подпись: такой APK **не обновит** установленное
  приложение — не ставить его поверх и не удалять старое без копии данных.

## Что проверить на телефоне
- Настройки → О приложении → Версия: номер сборки и коммит совпадают с запуском.
- Пройти по вкладкам Сегодня / Тело / Разум / Материальное / Хроника и по изменённым экранам:
  текст без чужих букв и штрихов (признак Impeller), ничего не обрезано на крупном шрифте.
- Если менялись разрешения, Health Connect, блокировка или шифрование — проверить именно их.
