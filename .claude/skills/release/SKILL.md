# Выпуск версии

Порядок — по `docs/RELEASE.md`, раздел «Выпуск версии». Тег и выпуск видны всем и необратимы по смыслу
(номер сборки уходит пользователям), поэтому каждый внешний шаг — **только с явного согласия владельца**.

## 0. Предпосылки (проверить и доложить)
- Секреты подписи заведены (`LIFEOS_KEYSTORE_BASE64` и др.): последняя сборка CI на `main` без предупреждения
  об отладочной подписи, в сводке есть `certificate SHA-256 digest`. Без ключа workflow выпуск не делает.
- CI на `main` зелёный.
- Номер новой версии согласован с владельцем (сейчас в `pubspec.yaml` — `version:`; посмотреть
  `git tag -l 'v*'` и `mcp__github__list_releases`). Семантика: исправления → патч, новые возможности → минор.

## 1. Версия в pubspec.yaml
- На рабочей ветке: `version: X.Y.Z+1` (число после `+` неважно — его заменит номер сборки из истории).
- Обновить в `CLAUDE.md` / `README.md` упоминания, если они про версию (например, «выпуск v1.0.0 ещё не делался»).
- Коммит, push, PR — только если владелец попросил. PR вливается **обычным merge** (не squash, не rebase).

## 2. Тег
После слияния в `main`:
```
git fetch origin main
git checkout --detach origin/main
grep '^version:' pubspec.yaml        # должно быть X.Y.Z
git tag vX.Y.Z && git push origin vX.Y.Z
```
Тег ставится **на коммит в main**, не на ветку. Если push тега запрещён правилами сессии — попросить владельца
выполнить две последние команды или создать выпуск/тег в GitHub самому.

## 3. Workflow «Выпуск»
`.github/workflows/release.yml` проверяет совпадение тега и версии, гоняет анализ и тесты, собирает подписанный APK
и создаёт выпуск с APK, `.sha256` и отпечатком подписи.
- Упал на «Тег … не совпадает с версией» — тег поставлен не на тот коммит. Удалять или переносить тег — только
  с согласия владельца.
- Упал на ключе — секреты не заведены (`docs/RELEASE.md`, раздел 2).

## 4. После выпуска
- Ссылка на выпуск, версия, номер сборки, отпечаток подписи — пользователю.
- Сверить отпечаток с прежними сборками: если отличается, обновление поверх не встанет.
- Напомнить: установка и обновление — открыть APK, «Обновить»; не удалять приложение без копии данных.
