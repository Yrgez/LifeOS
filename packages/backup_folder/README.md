# backup_folder

Локальный плагин Catenna: папка для резервных копий на Android через Storage Access Framework.
Человек один раз выбирает папку (можно облачную — например, Google Drive), приложение получает
постоянный доступ только к ней: пишет, перечисляет и удаляет свои файлы. Разрешений Android не требует.
Используется только через интерфейс `BackupStorage` (`lib/data/backup_storage.dart`).
