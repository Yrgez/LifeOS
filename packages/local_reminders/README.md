# local_reminders

Локальный плагин LIFE OS: напоминания без сервера и без сети. Приложение передаёт список «когда и что сказать»,
плагин ставит будильники Android (`AlarmManager.setAndAllowWhileIdle`, без разрешения на точные будильники),
показывает уведомления на своём канале и восстанавливает расписание после перезагрузки. Текст на экране
блокировки скрыт. Используется только через интерфейс `ReminderScheduler` (`lib/data/reminder_scheduler.dart`).
